# Ремонт натяжных потолков — Миасс, Златоуст, Чебаркуль, Карабаш

Демонстрационный сайт на Next.js App Router, React и TypeScript. Данные хранятся в обычном JSON; база данных и серверный приём заявок не используются.

## Локальный запуск

Требуется Node.js 20.9 или новее; рекомендуется Node.js 24 LTS. Используйте npm и включённый `package-lock.json`, чтобы установить те же версии зависимостей.

Откройте терминал в папке проекта:

```sh
npm ci
npm run dev
```

Откройте http://localhost:3000. Для остановки нажмите Ctrl+C.

## Локальная production-сборка

```sh
npm run build
```

Готовый статический сайт находится в `out/`. Его можно разместить на любом статическом HTTP-сервере. Например, если установлен Python 3:

```sh
python3 -m http.server 3000 --directory out
```

После запуска откройте http://localhost:3000. На Windows вместо `python3` может использоваться `py`.

Проект настроен на `output: 'export'`, поэтому `next start` для этой сборки не применяется. Для разработки используйте `npm run dev`, для размещения — папку `out/`.

Проверка типов: `npm run typecheck`.

Ключи API, аккаунт Sites и переменные окружения для локального запуска не требуются. `.openai/hosting.json` относится к исходной публикации через Sites и не используется локальным Next.js.

Перед размещением на собственном домене замените `origin` в `app/layout.tsx`. Индексация сейчас отключена через `robots`, поскольку контент демонстрационный. Шрифты загружаются из Google Fonts; если сеть недоступна, используется системный шрифт. Все изображения включены в архив.

В архиве находятся исходники последней опубликованной версии (коммит `55738014de0361c4d5ab784be3f849743a9996b8`) с дополненной инструкцией локального запуска. Зависимости, сборочные каталоги и служебная папка `.git` не включены. При необходимости создайте собственный репозиторий командами `git init` и `git add .`.

## Содержание

- `data/site.json`: название, телефон, города, описание и главное изображение.
- `data/hero.json`: тексты первого экрана, состояния «Проблема / Решение» и подписи изображения.
- `data/services.json`: услуги, подробные описания и состав работ.
- `data/content.json`: этапы работы и примеры ситуаций.
- `data/installation.json`: секция монтажа, варианты обновления, изображение и состояния «До / После».
- `data/projects.json`: примеры объектов и фотографии.
- `data/prices.json`: демонстрационный прайс.
- `data/faq.json`: вопросы и ответы.
- `public/images/`: изображения, используемые в макете.

После изменения JSON требуется повторная сборка и публикация.

## Что заменить перед запуском

1. Название и тестовый номер `+7123456789` на данные компании. Все кнопки звонка используют один номер из JSON.
2. Иллюстративные фотографии и демо-описания объектов на реальные работы. Указать фактические города и результаты.
3. Все демонстрационные цены на подтверждённый прайс или убрать блок цен.
4. Уточнить график, условия выезда, гарантии и способы связи. Они не выдуманы для макета.
5. Добавить мессенджер после получения реальной ссылки.
6. После замены тестового контента убрать демо-пометки и разрешить индексацию в `app/layout.tsx`.

Фотографии интерьеров загружены с Unsplash и служат иллюстрациями, а не доказательством выполненных компанией работ. Изображение первого экрана с двумя состояниями потолка сгенерировано: левая половина показывает залив, правая — возможный результат ремонта. Для блока монтажа создано отдельное изображение старого и обновлённого потолка в одной комнате. У каждого блока собственный переключатель: он перемещает изображение внутри кадра, подписи и alt меняются вместе с ним. Это демонстрационные сценарии, а не реальные кейсы или гарантия восстановления.

Города обслуживания задаются в `site.json` и используются в первом экране, контактах, подвале, срочной помощи и выборе города. Текст FAQ и SEO-описание также обновлены для Миасса, Златоуста, Чебаркуля и Карабаша. Шрифты увеличены по всему сайту; на узких экранах карточки перестраиваются в одну колонку.

## Поведение

Карточки услуг открывают доступный диалог с описанием; Escape и кнопка закрытия закрывают его. FAQ раскрывается через нативный `details`. Выбор ситуации показывает справочную рекомендацию без отправки или хранения персональных данных. Кнопки связи используют `tel:`. На мобильном экране есть меню и закреплённая кнопка звонка.

Сайт создан для показа заказчику. Демонстрационный номер намеренно сохранён в указанном пользователем виде; он не является проверенным рабочим номером.
